# simple-backups iOS companion (stub)

Minimal SwiftUI shell so an Xcode project can grow beside the Android scaffold.
Emulator CI is deferred; focus remains on the Rust CLI.

Open `SimpleBackups/SimpleBackupsApp.swift` in a new Xcode iOS App project, or
generate one later with:

```text
Product name: SimpleBackups
Bundle id:    com.simpletools.backups
Language:     SwiftUI
```
